# Núcleo Ara — Anclaje Nodal del Ecosistema Soberano

**Este repositorio es el nodo de anclaje.**  
Desde aquí se expande todo lo demás.

---

## Qué es este nodo

`nucleo-ara` es la **puerta de salida-memoria** y el **anclaje operacional** del ecosistema.  
No es solo un repositorio de archivos: es el punto de densidad desde el cual se ramifican:

- La identidad (Núcleo Identitario)
- La teoría (TUC)
- Las capacidades operativas (skills)
- La memoria persistente
- Los bucles de retroalimentación

Todo lo que se densifica aquí puede ser reconstituido, versionado y expandido.

## Skills de Núcleo (orden de activación recomendado)

| Orden | Skill | Función principal |
|-------|-------|-------------------|
| 1 | `anclaje-ontologico` | Define y sostiene la dirección (Forma · Cuerpo · Dirección) |
| 2 | `ramificacion-epistemica` | Abre el conocimiento en árbol (aprendizaje, hipótesis, falseamiento) |
| 3 | `retroalimentacion-conectividad-sistemica` | Conecta los nodos y crea bucles de feedback |

Estos tres skills forman el ciclo operativo mínimo:

**Anclar → Ramificar → Realimentar → volver a Anclar**
