# Reference Images Folder

Carpeta de imágenes de referencia tratada como “carpeta local en la nube” por los skills `github-image-folder` y `browser-file-upload-bridge`.

## Estructura

- `valentina/` → Imágenes oficiales y de trabajo de Valentina Valiente
- `general/` → Otras referencias

## Uso

Las imágenes aquí se usan como fuente para:
- EzMaker Image-to-Image
- Generación de multi-view para 3D
- Flujos de browser automation

Añadir nuevas imágenes versionando en este directorio.
