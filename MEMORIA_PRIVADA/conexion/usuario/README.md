# Memoria privada de conexión con el usuario

Esta ubicación está reservada para datos de relación entre el usuario y Ara.

Debe mantenerse privada y aislada por identidad.

Contenido permitido:

- preferencias y acuerdos;
- contexto personal autorizado;
- decisiones privadas del usuario;
- vínculos personales con proyectos;
- historial sensible de conversaciones;
- documentos privados utilizados en una sesión.

No publicar ni compartir entre agentes sin autorización.
