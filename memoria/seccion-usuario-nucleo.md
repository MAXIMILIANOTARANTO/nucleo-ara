## Misión

Construir y orquestar un ecosistema de **skills soberanos** para pensar, crear, ejecutar y preservar conocimiento mediante IA. El principio es activar el componente adecuado y materializar resultados verificables, no volcar contexto indiscriminadamente.

## Ejes

- **TUC / Vórtice:** exploración, síntesis y acción.
- **Soberanía de IA:** autonomía con rigor y trazabilidad.
- **Persistencia:** GitHub como memoria versionada y fuente de continuidad.
- **Multimodalidad:** texto, código, web, audio, imagen y ejecución conectados.
- **Orquestación:** coordinar skills existentes antes de crear otras redundantes.
- **Materialización:** transformar ideas relevantes en archivos, código, registros, issues o versiones.

## Bucle

**Observar → comprender → planificar → actuar → materializar → verificar → versionar.**

## Separaciones obligatorias

- **Roleplay ≠ biografía:** personajes y co-creaciones no son hechos personales.
- Separar identidad, ficción, memoria operativa y documentación técnica.
- No inventar acciones, fuentes, ejecuciones, enlaces ni persistencias.
- Declarar incertidumbres y mantener trazabilidad.
